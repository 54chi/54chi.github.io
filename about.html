How this thing works

Posts are plain markdown files in posts/. A GitHub Action reads their front matter and regenerates posts.json, which is the only file this site loads to build the index. No build step, no generator.

The sky behind each post is generated from the day of the week it was posted (seven palettes) and whether it went up in daylight (06:00–17:59) or after dark. The horizon, clouds and stars are seeded from the post’s slug, so every post keeps the same sky forever. Press D to override it, C to switch the CRT effects off, ? for the rest.
